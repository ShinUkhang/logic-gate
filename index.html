명제의 포함관계, NAND 만능 게이트 & 0~32 카운터 회로

학년 / 반 1학년    반    번 성명 확인 (인)
💡 1분 핵심 개념 : $P \subseteq Q$ 일 때 명제 $p \to q$는 참이며 $p$는 충분조건, $q$는 필요조건입니다. 반도체 공학에서는 드모르간 법칙 덕분에 NAND 게이트 하나만으로 모든 논리 연산을 처리하며, 이를 결합하여 0부터 32($2^5$)까지 숫자를 카운트하는 가산기 회로를 만듭니다!
✍️ [활동 1] 진리집합 포함관계와 필요·충분조건 판정
조건 $p$ vs 조건 $q$ 진리집합 포함관계 성립하는 화살표 $p$는 $q$이기 위한?
$p$: $x$는 4의 배수
$q$: $x$는 2의 배수		 $P = \{4, 8, 12, \dots\}$
$Q = \{2, 4, 6, 8, \dots\}$		 $P \subseteq Q$ 이므로
$p \implies q$ (참)		 ( 충분 / 필요 ) 조건
$p$: $x$는 2의 배수
$q$: $x$는 4의 배수		 반례: $x = $ [ ]
$Q \subset P$ ($P \not\subseteq Q$)		 $q \implies p$ 성립
$p \not\implies q$ (거짓)		 ( 충분 / 필요 ) 조건
⚡ [활동 2] 반도체의 기적: NAND 게이트 하나로 모든 연산 처리하기
드모르간 법칙에 의해 NAND (둘 다 1일 때만 0)만 조합하면 모든 기본 게이트가 합성됩니다.
만들고 싶은 연산 NAND 게이트 연결 방법 (수학식) 동작 확인
NOT(A) $\text{NAND}(A, A) = \overline{A \cdot A} = \bar{A}$ 0 넣으면 1, 1 넣으면 0 (성공)
AND(A, B) $\text{NOT}(\text{NAND}(A, B)) \implies$ NAND 출력을 다시 묶음 둘 다 1일 때만 1 출력 (성공)
OR(A, B) 드모르간: $\text{NAND}(\bar{A}, \bar{B}) = \overline{\bar{A} \cdot \bar{B}} = A + B$ 하나라도 1이면 1 출력 (성공)
👉 삼성전자/SK하이닉스가 NAND를 대량 생산하는 이유: NAND 하나만 반복 배치하면 CPU, GPU, 메모리 등 모든 복잡한 논리 회로를 100% 다 제작할 수 있기 때문입니다!
🔢 [활동 3] 논리 게이트 회로로 0부터 32까지 숫자 세기 (2진수 가산기)
컴퓨터는 XOR(합 Sum)과 AND(올림수 Carry) 게이트를 연결한 반가산기(Half Adder)로 2진수 덧셈을 합니다.
10진수 숫자 5비트 2진수 ($2^4, 2^3, 2^2, 2^1, 2^0$)
00 0 0 0 0 (스위치 모두 OFF)
10 0 0 0 1 ($2^0$)
20 0 0 1 0 ($2^1$)
30 0 0 1 1 ($2^1 + 2^0$)
········· (가산기 회로로 1씩 증가)
10진수 숫자 5~6비트 2진수 출력
161 0 0 0 0 ($2^4$)
311 1 1 1 1 ($16+8+4+2+1$)
★ 32 ★1 0 0 0 0 0 (6번째 비트 올림!)
스위치 5~6개로 0부터 32까지 표현 완성!

퍼셉트론 1차 부등식 손계산 & XOR의 최종 수학적 도출

학년 / 반 1학년    반    번 성명 확인 (인)
💡 1분 핵심 개념 : 단층 퍼셉트론 $z = w_1 x_1 + w_2 x_2 + b$ 는 직선 1개이므로 XOR을 분리할 수 없습니다. 하지만 명제 논리의 결합: $\text{XOR} = \text{OR} \land \text{NAND}$ 을 이용하면 직선 2개(다층 퍼셉트론)로 완벽히 해결할 수 있습니다!
✍️ [활동 1] AND 게이트: 점 4개를 퍼셉트론 식($2x_1 + 2x_2 - 3$)에 대입 계산
점 $(x_1, x_2)$ 대입 계산 식 $z$ 계산값 $z \ge 0$ 인가? 출력 $y$ 정답(AND)
$(0, 0)$ $2(0) + 2(0) - 3$ -3 거짓 ($< 0$) 0 (파랑) 0 (일치)
$(1, 0)$ $2(1) + 2(0) - 3$ ( 참 / 거짓 ) 0 (일치)
$(0, 1)$ $2(0) + 2(1) - 3$ ( 참 / 거짓 ) 0 (일치)
$(1, 1)$ $2(1) + 2(1) - 3$ ( 참 / 거짓 ) 1 (일치)
✍️ [활동 2] 좌표평면에 직접 자를 대고 AND 결정경계 직선 긋기
📏 자 대고 직선 긋기 미션:
• $x_1$ 절편 $(1.5, 0)$과 $x_2$ 절편 $(0, 1.5)$를 찾아 자로 연결하세요!
• 직선 위 $(1,1)$은 빨간색(1), 아래 3개 점은 파란색(0)으로 색칠하세요.
🌟 [활동 3] XOR 연산을 OR과 NAND로 최종 도출하는 수학적 과정
수학적 동치 관계: $x_1 \oplus x_2 \equiv (x_1 \lor x_2) \land \sim(x_1 \land x_2) \equiv \mathbf{OR(x_1, x_2) \land NAND(x_1, x_2)}$

아래 표의 빈칸을 채워, 1층(은닉층)과 2층(출력층)을 거치며 XOR이 완벽히 도출되는 과정을 확인하세요!

입력 $(x_1, x_2)$ 1단계: $s_1 = \text{NAND}$
(1,1 제외)		 1단계: $s_2 = \text{OR}$
(0,0 제외)		 2단계: $y = \text{AND}(s_1, s_2)$
(두 신호의 교집합)		 최종 XOR 목표값
$(0, 0)$ 1 0 $\text{AND}(1, 0) =$ 0 0 (일치!)
$(1, 0)$ 1 1 $\text{AND}(1, 1) =$ [   ] 1 (일치!)
$(0, 1)$ 1 1 $\text{AND}(1, 1) =$ [   ] 1 (일치!)
$(1, 1)$ 0 1 $\text{AND}(0, 1) =$ [   ] 0 (일치!)
👉 수학적 의미: 단일 직선으로는 불가능했던 XOR을 'NAND 직선과 OR 직선 사이의 교집합($\cap$)'으로 완벽히 해결했습니다! (다층 퍼셉트론 / 딥러닝의 원리)
